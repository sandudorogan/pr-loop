How it works · one round

From a push to Ready

Each round looks only at what changed since the last one.

01

Review

Three reviewers read the new commits, the task brief, and the repo's own conventions.

Each posts one review with inline comments.

02

Filter

A finding counts at severity ≥ medium and confidence ≥ 0.6.

From round 4: ≥ high only.

03

Fix · your PRs

Codex edits in a sandbox: no git, no network.

The project's gates run: format, then test.

PR Wizard commits, pushes, replies and resolves the threads.

04

Stop

Every reviewer clean: Ready.

8 rounds in a row with findings: it waits for a human.

What it covers

Which PRs, and what it looks at

Review lane

  • PRs you opened
  • PRs that request your review
  • PRs assigned to you
  • PRs you reviewed before
  • Reads the repo's AGENTS.md, CLAUDE.md, contributing doc, editorconfig, linters

Fix lane · your PRs only

  • Unresolved review threads
  • Review bodies on the current head
  • Failed GitHub Actions jobs
  • Merge conflicts with the base
  • Then the project's gates, e.g. cljfmt and Karma

Left alone

  • Repos without a local checkout
  • PRs that add more than 4000 lines
  • Only trivial files (lock files, docs, images)
  • PRs labeled no-auto-review / no-auto-fix
What to expect

It works as you, in the open

  • Reviews, replies and commits go out with your GitHub credentials.
  • Fix commits land on your branch. Codex never runs git; PR Wizard commits and pushes.
  • When one engine hits its usage limit, the reviewer runs on the other.
  • One notification only: “Ready for your approval” when a colleague's PR comes back clean.
  • Opt a PR out with a label. Pause one PR in the app, or every lane with --pause.
  • Needs macOS 26, Python 3.10+, gh logged in, Claude Code and Codex.
The CLI

Everything the app does, from the terminal

$ pr-wizard -l # the queue: ▶ in work · 1..n next · ✓ ready
$ pr-wizard --pr 16400 # review one PR now
$ pr-wizard --next 16400 # move a PR to the front
$ pr-wizard --wait 16400 # block until it settles, print JSON
$ pr-wizard --pause # take no new PR until --resume
$ pr-wizard config --patch '{"review": {"workers": 2}}'
